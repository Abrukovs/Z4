## ⚠️ ПОСТОЯННЫЕ ПРАВИЛА (каждый агент, каждый запуск)

Скрипт вернёт настройки бота из `.git/local-backup/` (папка внутри .git — переживает сбросы, никогда не пушится в GitHub). Затем БД наполнится авто-сидингом при первом визите сайта.
1. **Бэкап в начале работы:** `bash .zscripts/backup-db.sh` (снимок SQLite VACUUM INTO → backups/, дублируется в .git/local-backup/, ротация 14).
2. **Запрещены деструктивные операции с БД:** `db:reset`, `prisma migrate reset`, `db push --force-reset`, удаление db/custom.db, чистка таблиц. Изменения prisma/schema.prisma — только после бэкапа.
3. **Синхронизация с GitHub (просьба владельца от 16.10):** `bash .zscripts/git-sync.sh "описание"` — коммит всегда, ПУШ не чаще раза в сутки (троттлинг внутри скрипта; после ночного сброса штамп пропадает → первый пуш дня происходит утром — это штатно). Ручной немедленный пуш: `git-sync.sh push "описание"` или кнопка «Сохранить на GitHub» на сайте (внизу вкладки «Статистика», POST /api/github/push). Без просьбы владельца троттлинг не обходить.
4. **ChunkLoadError в браузере** после перезапусков dev-сервера — штатная особенность dev-режима (старые чуки), лечится жёстким обновлением страницы (Ctrl+F5). Не «чинить» кодом.
5. Секреты в git не попадают (db/, .env, токены — .gitignore). Не ослаблять. Токен бота хранится ТОЛЬКО в БД и в .git/local-backup/bot-settings.json.
6. По завершении — дописать Task-секцию в конец журнала (шаблон: Task ID / Agent / Task / Work Log / Stage Summary).
